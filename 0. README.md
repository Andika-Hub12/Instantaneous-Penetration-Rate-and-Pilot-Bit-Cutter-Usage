# Instantaneous-Penetration-Rate-and-Pilot-Bit-Cutter-Usage
This is a combination of Excel and Power BI script to filter historical database for Raisebore Project Estimation Purpose.

Historical Data is transformed from a raw format into a filter-able format as visualized in "01. Historical-Data-Transformation_VBA-Result.xlsx with "00. VBA-Code_Historical-Data-Transfomation"

Then, the filter-able data is processed and based on an algorithm created from Senior Project Estimator's way of thinking determining when a data is considered as Pilot Bit or Cutter Change while Piloting or Reaming. The algorithm is recorded on "00. Excel-Codes"

Next, excel data is presented on Power BI with some new measures recorded on "00. PowerBI_Dax_Codes" and the visualization are shown on all 02.jpgs visualizations

This filter-able dashboards help the senior estimator to get historical performances of the same area/geology/company when the new tenders came to the table within seconds. These figures help him while estimating schedule and cost to submit the service-tender pricings
